## Visão geral

Esse projeto é o motor preditivo do sistema PrevUni. A API recebe dados acadêmicos de estudantes, processa os atributos através de um modelo treinado de **Random Forest** (~95% de acurácia) e retorna a probabilidade percentual de evasão categorizada em três níveis: **Baixo**, **Moderado** e **Alto**.

---

## Tecnologias utilizadas

- **Python** & **FastAPI**
- **Scikit-Learn** & **Joblib**
- **Pandas** & **Pydantic**
- **Vercel**
